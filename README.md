# MistRVC

Форк проекта [MuXVS](https://github.com/MuXolotl/MuXVS), адаптированный для удобного использования в Google Colab. 

Конвертация голоса (RVCv2), обучение моделей и разделение аудио (UVR) в одном минималистичном веб-интерфейсе на Gradio. Работает на Python 3.13.

## Основные возможности

- **Конвертация** — замена голоса с тонкими настройками и пакетной обработкой.
- **Обучение** — полный цикл: нарезка, извлечение признаков, обучение и создание индекса.
- **UVR** — разделение аудио на стемы (Roformer, MDX23C, MDX-NET, VR Arch, Demucs).
- **Инструменты** — проверка моделей, разделение чекпоинтов, апскейл аудио.
- **Настройки** — настроить цвет интерфейса под желаемый.
